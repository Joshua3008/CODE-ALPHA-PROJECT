# CODE-ALPHA-PROJECT
During my CodeAlpha Artificial Intelligence internship, I completed three hands-on projects covering natural language processing, web development, and deep learning.

1. Language Translation Tool: A web app that translates text between 30 languages using the MyMemory Translation API, with copy-to-clipboard, text-to-speech, and a language-swap feature.

2. FAQ Chatbot: A chatbot that preprocesses user questions, converts them to TF-IDF vectors, and uses cosine similarity to return the best-matching answer from an FAQ dataset. It comes with a Flask chat interface and confidence scoring.

3. Music Generation with AI: A deep learning pipeline that parses MIDI files with music21, trains an LSTM network to learn note and chord patterns, and generates new music sequences saved as playable MIDI files.

Tech stack: Python, TensorFlow/Keras, scikit-learn, Flask, music21, NumPy, HTML/CSS/JavaScript.

Each project has its own GitHub repository, following the CodeAlpha_ProjectName naming convention, with full source code and documentation included
